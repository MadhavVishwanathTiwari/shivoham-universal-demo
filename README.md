# Shivoham Universal Sol

A client-facing demo site. The hero is a 78-card tarot deck rendered in 3D: the deck deals itself into a sine-wave ribbon across the screen, each card turns to meet your pointer, and scrolling gathers the spread back into a stack.

**Stack:** Next.js 16 (Turbopack) · React 19 · React Three Fiber + drei · three.js · Framer Motion · Tailwind 4

## Running it

```bash
npm install && npm run dev
```

Serves on **http://localhost:3002**. The port is pinned deliberately — see `CLAUDE.md`.

| Command | What it does |
| --- | --- |
| `npm run dev` | Dev server on `:3002` |
| `npm run typecheck` | `tsc --noEmit` — use this, not a full build, to check types |
| `npm run build` | Production build. **Never run while the dev server is up** — they share `.next/` and it will break the running server |
| `npm run assets` | Rebuilds the card atlas + GLB via `tools/build_deck.py`, then verifies |

## Layout

```
src/app/              Next App Router shell
src/components/hero/  The 3D hero — everything interesting lives here
  HeroSection.tsx     Scroll/gesture orchestration, copy, tooltips
  HeroCanvas.tsx      R3F stage: camera, lighting, environment
  TarotDeck3D.tsx     The deck itself — all motion, one InstancedMesh
  cardData.ts         Card list, atlas UV math, model constants
tools/                Python asset pipeline (atlas + card.glb)
```

## Assets

The deck is one `InstancedMesh`: 3 draw calls and 2 textures for all 78 cards. Card faces come from a single atlas sampled per-instance via a patched vertex shader. The mesh is generated by `tools/build_card_glb.py` and **must** expose three primitives named `face`, `back`, and `rim` — `TarotDeck3D` throws on load if it doesn't.

## Before changing the hero

Read the comments in `TarotDeck3D.tsx`. They document real invariants — notably the `WAVE_LAYER > PI * WAVE_DEPTH` depth-ordering rule and the invisible hit-proxy mesh — that have no visible symptom when broken until interaction falls apart.

`CLAUDE.md` covers the dev-server rules and known environment traps.
